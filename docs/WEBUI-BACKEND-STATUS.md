# WebUI 本地构建验收记录

更新：2026-09-29。源码实现与隔离验证记录；未推送版本、未发布镜像、未修改生产。

## 实现范围

- 单管理员首次设定账号和密码、登录、退出、验证旧密码后改密；密码哈希保存，改密注销全部会话，登录限速。
- 四模式配置、角色向导、真实配置摘要、保存、版本冲突保护、备份恢复到编辑区；管理格式和运行格式独立，未知字段拒绝。
- 缺失密钥生成、保留已有密钥、加密媒体交接包导出/导入、冲突拒绝。
- 证书上传/粘贴、私钥配对、域名和有效期验证；证书由程序保存，应用后使用。不自动签发、续期、同步。
- STRM 来源目录到主代理本地副本目录的实际映射；媒体服务不读 STRM。路径边界、遍历、符号链接越界受限制。
- 真实运行配置转换、受控子进程应用、失败恢复旧进程、重启只恢复成功应用的快照。旧镜像入口保持兼容，管理入口显式启用。
- 诊断、最近 100 条脱敏操作记录、脱敏诊断下载；记录不含密码、私钥、播放令牌和完整视频链接。
- 已确认的界面布局，核对页展示实际参数；顶部状态和等高按钮分组，窄屏整组换行。

## 已执行验证

- `go test -race ./...` 与 `go vet ./...` 通过。
- 三组 UI 自动测试通过：原有模块、四模式、实际管理交互。
- `RUN_MANAGEMENT_INTEGRATION=1 go test ./internal/management -run TestRuntimeBinaryFourModes -count=1 -v` 通过：真实二进制、管理接口保存/应用、陈旧版本 409、四模式实际地址路径、GET/HEAD、Range 206 和返回字节、停止及 Resume。
- 本地浏览器验证登录、向导、保存到版本 1、配置摘要。检查视口 805×732 无横向溢出。
- Docker 镜像本地构建通过，隔离容器返回首次管理员未初始化状态。

## 边界

同源中继目前仅支持飞牛；单容器直出每份配置选择一种服务。传统多服务共用目录映射，差异组合明确拒绝；分机模式可以按服务独立设置。不同目录映射不负责同步文件，也不能替用户创建 Docker 挂载。

导入接受本管理界面导出的管理 JSON/YAML，不把旧运行 YAML 静默转换。配置导出不含秘密；媒体交接包含共享密钥但不含证书私钥或管理员密码。完整灾备需安全备份整个管理数据卷。

本地模拟源的协议验收不能替代现网飞牛/Emby/Jellyfin 客户端起播、拖动及公网流向验收。本轮没有操作生产环境。证书上传保存与运行使用分开，页面提示应用后生效。
