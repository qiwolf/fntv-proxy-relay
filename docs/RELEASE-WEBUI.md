# v0.9.8-relay.4 发布说明

## 新增

- Web 管理入口：单管理员首次创建账号、登录、退出及修改密码。
- 四种播放模式的配置向导、配置摘要、保存与应用、版本冲突保护、历史恢复和诊断。
- 共享密钥生成、加密媒体配置包导入与导出；分机主代理在向导最后核对后导出。
- 视频证书上传或粘贴，自动私有保存；不自动签发、续期或同步证书。
- STRM 来源目录到主代理本地目录的映射，支持两端路径不同；不代替文件同步或挂载。
- 应用失败尝试恢复旧运行版本，重启恢复最后成功应用的配置。

## 使用和升级

管理入口为 `/app/fntv-manager`，需显式配置 entrypoint，并持久化管理数据目录。
镜像默认入口不变，升级镜像不会自动迁移原有 YAML 或启用管理界面。
部署步骤见 [WEBUI.md](WEBUI.md) 和 [Compose 示例](../compose.manager.yaml.example)。

管理入口默认只监听本机；非本机监听需可信 HTTPS 反代及访问限制。
首次设置管理员前不要公开管理入口。管理数据卷包含敏感材料，必须私有保存并安全备份。

## 明确限制

- 同源中继当前仅支持飞牛；单容器直出每份管理配置选择一种服务。
- 分机直出支持飞牛、Emby、Jellyfin，媒体服务不需要挂载 STRM。
- 管理配置导入只接受管理格式，不自动转换旧运行 YAML。
- 路由器映射、防火墙、Docker 端口及目录挂载仍需部署者配置。
- 重复重启可能积累私有运行历史目录；当前不自动清理跨重启历史。
